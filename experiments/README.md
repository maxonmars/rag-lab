# Эксперименты

Отчёты сравнений с воспроизводимыми измерениями и выводами. Сейчас: [feod-chunking](feod-chunking/README.md) —
сравнение двух стратегий чанкинга на документации FEOD. Runner и метрики качества поиска не реализованы.
В сравнении одинаковы корпус, модель и параметры, измеренные значения отделяются от оценок, внешние данные и версии
фиксируются. Проверка качества поиска появится вместе с заданием, которое вводит поиск.
