# Эксперименты

Отчёты сравнений с воспроизводимыми измерениями и выводами. Сейчас:

- [feod-chunking](feod-chunking/README.md) — сравнение двух стратегий чанкинга на документации FEOD;
- [feod-rag](feod-rag/README.md) — 10 контрольных вопросов ([questions.md](feod-rag/questions.md)): ответы без RAG и с RAG.

Runner и агрегированные метрики качества поиска (hit@k, MRR) не реализованы: `rag eval` считает только попадание
ожидаемых файлов в top-K. В сравнении одинаковы корпус, модель и параметры, измеренные значения отделяются от оценок,
внешние данные и версии фиксируются.
