## Ориентиры будущих решений

- Поиск по индексу сначала линейный перебор: при сотнях чанков FAISS и sqlite-vec не нужны.
- Модели с инструкцией для запросов (Qwen3-Embedding) требуют разных текстов для документов и запросов; `bge-m3` — нет.
- Качество поиска измеряется на фиксированных вопросах с известными источниками; измеренное отделяется от оценок.
- Смена модели эмбеддингов или параметров чанкинга требует пересборки индекса.
- Сравнение моделей эмбеддингов на этом корпусе — кандидат для отдельного задания.
