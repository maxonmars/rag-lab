# Источники, цитаты и «не знаю»

Цель: показать, что ответ RAG содержит источники и цитаты, а код проверяет цитаты на дословность; при пустом контексте после
отбора по порогу ассистент отвечает «не знаю» без вызова модели. Решение — [ADR 0005](../adr/0005-citations-and-refusal.md),
результаты на 10 вопросах — [experiments/feod-citations](../../experiments/feod-citations/README.md).

## Требования

- индекс из [демо индексации](indexing.md): `npm run corpus:feod`, затем `npm run dev -- rag index`;
- запущенная Ollama с той же моделью, что при построении индекса (`bge-m3`, [docs/ollama.md](../ollama.md));
- `LAB_LLM_API_KEY` в корневом `.env` для `rag ask` и `rag citations`.

## Сценарий

1. Вопрос, ответ на который есть в корпусе. Режим по умолчанию — `rewrite-filter`.

```sh
npm run dev -- rag ask "Что можно хранить в global?"
```

Ожидается блок `── Ответ агента · RAG · <провайдер · модель> ──`: текст ответа со ссылками `[N]`, затем `Источники:` — по строке на фрагмент
(номер, файл, разделы, `chunk_id` вида `structure:structure/global.md#001-…` и URL документа), затем `Цитаты:` — строки
вида `- [2] «…» — найдена во фрагменте 2` и в конце `Фрагменты:`. `[N]` — номер фрагмента из списка «Фрагменты»; файл,
разделы, `chunk_id` и URL раскрывает код. Пометка «не найдена во фрагменте» и блок `Замечания:` появляются, если цитаты нет в
тексте чанка или нарушен формат ответа.

2. Вопрос без ответа в корпусе, которому не хватает сходства.

```sh
npm run dev -- rag ask "Какой state-менеджер рекомендует FEOD?"
```

Ожидается `Не знаю: ни один фрагмент не достиг порога сходства 0.55 (лучшее …)`, просьба уточнить вопрос, список ближайших
разделов ниже порога и `Фрагменты: контекст пуст`. Модель при этом не вызывалась (rewrite выполняется до поиска, генерации нет).

3. Вопрос без ответа, фрагменты по которому порог пропускает.

```sh
npm run dev -- rag ask "Какую версию React требует FEOD?"
```

Фрагменты переданы (список «Фрагменты» не пуст), и отказ формулирует сама модель: `Не знаю. …` и `Уточнение: …`. Такой отказ
не гарантирован: модель может ответить иначе, и именно в этом отличие от шага 2.

4. Прогон 10 контрольных вопросов эксперимента в настроенном режиме. Ход печатается в stderr (`q02: ответ с источниками`, …), итог —
   в stdout.

```sh
npm run dev -- rag citations --rag-questions-file experiments/feod-citations/questions.md
cp .local/rag/rag-citations.md experiments/feod-citations/rag-citations.md
```

Ожидается блок `── Контрольные вопросы ──`: строки «Положительные» (с источниками, с цитатами, ожидаемый файл среди источников,
«не знаю»), «Отрицательные» (число «не знаю» с разбивкой: пустой контекст или модель), «Цитаты дословно», длительность и путь
к `.local/rag/rag-citations.md`. В отчёте — сводка, таблица вопросов, переданные фрагменты с `chunk_id` и ответы. Смысл ответов в
отчёте не оценивается: его читает автор и записывает в README эксперимента.

## Ошибки

Нарушение формата ответа (нет раздела, номера вне контекста, цитата не из своего фрагмента) не прерывает работу: ответ
показывается целиком, а блок `Замечания:` называет причину. Остальные ошибки — как в [демо RAG-запроса](rag-query.md):
нет индекса, ключа, Ollama, файла вопросов (`rag.questionsFile`). Ошибка модели во время `rag citations` записывается в отчёт как
исход вопроса и считается в строке «Ошибки модели»; ошибки Ollama-эмбеддингов, индекса и файла вопросов прерывают прогон.

## Ограничения

Цитата засчитывается как подстрока текста чанка после нормализации регистра, «ё», пробелов, Markdown-символов, тире и кавычек;
перефразирование не распознаётся, а дословная цитата не доказывает, что ответ ей следует. Ссылки `[N]` внутри текста ответа
и позиция цитаты в документе не проверяются. Нарушение формата не повторяется. Порог 0.55 откалиброван для поиска, а не для отказа:
q14 его проходит, и тогда отказ зависит от модели. DeepSeek недетерминирован, прогон один.
