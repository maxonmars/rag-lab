# Команды

Генерируется из реестра: `npm run docs:generate`.

CLI: `npm run dev -- <команда>`. Без команды запускается REPL; обычная строка вызывает ask.
CLI-флаги задаются при запуске. В REPL настройки не изменяются.
CLI использует quoting оболочки; в REPL остаток /ask передаётся как текст без обработки кавычек.

| CLI | REPL | Описание |
|---|---|---|
| ask <текст...> | /ask | Отправить реплику модели в режиме сессии: без поиска по документам, а после /rag on — с RAG. Истории между репликами нет. Нужен LAB_LLM_API_KEY. |
| help | /help | Показать команды и флаги настроек. |
| config show | /config show | Показать действующие настройки и их источники без значений секретов. |
| rag index | /rag index | Разбить корпус двумя стратегиями (fixed и structure), получить эмбеддинги через Ollama и сохранить оба индекса в index.json. Нужны запущенная Ollama и скачанная модель. |
| rag compare | /rag compare | Прочитать сохранённый index.json и записать отчёт comparison.md со сравнением стратегий без обращения к модели. |
| rag ask <текст...> | /rag ask | Найти в index.json фрагменты по вопросу и ответить по ним; всегда с RAG, независимо от режима сессии. Нужны индекс, запущенная Ollama с моделью индекса и LAB_LLM_API_KEY. |
| rag on | /rag on | Включить режим RAG до конца сессии REPL: обычные строки и /ask отвечают с поиском по индексу. В CLI действует только на этот запуск. |
| rag off | /rag off | Выключить режим RAG до конца сессии REPL: обычные строки и /ask отвечают без поиска. В CLI действует только на этот запуск. |
| rag eval | /rag eval | Прогнать контрольные вопросы в обоих режимах, без RAG и с RAG, и записать отчёт rag-eval.md. Нужны индекс, запущенная Ollama, LAB_LLM_API_KEY и файл вопросов из rag.questionsFile. |
| exit | /exit | Завершить ввод реплик. |

Алиасы help: --help, -h.
Чтобы передать текст, начинающийся с --, используйте `ask -- <текст>`.
