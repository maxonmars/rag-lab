# Правила llm-gateway

Общие правила находятся в [корневом AGENTS.md](../../AGENTS.md).

- main.ts читает `process.env` и сигналы, compose.ts связывает модули; остальные файлы `process` не используют.
- Сервер не импортирует `apps/` и другие серверы; зависимостей времени выполнения нет, только `node:*` и глобальный `fetch`.
- Ключи не попадают в лог, сообщения ошибок и вывод; в логе — порядковый id (`key1`).
- Лимиты — переменные `GATEWAY_*` или именованные константы, не числа внутри логики.
- Ollama остаётся на `127.0.0.1`; шлюз проксирует только `/v1/chat/completions` (в Ollama) и `/v1/rag/*` (в `rag serve` на `127.0.0.1:8788`, ADR 0010), `/v1/models` формирует сам.
- Состояние лимитов живёт в памяти процесса. Тесты используют подменённый `fetch` и инжектируемое время.
